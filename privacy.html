TrioBoard — Privacy Policy

Последнее обновление / Last updated / עדכון אחרון: 2026-11-24

1. Отсутствие скрытой телеметрии и локальное хранение

TrioBoard работает по принципу «приватность прежде всего». Приложение не собирает аналитику, не отслеживает нажатия клавиш, не строит рекламные профили и не передаёт данные разработчикам.

  • В версии из Microsoft Store (MSIX) и при установке в системную папку настройки, словарь, автотекст, история буфера, пользовательские API-ключи и скачанные модели хранятся исключительно локально в профиле пользователя Windows: %LOCALAPPDATA%\TrioBoard\data и %LOCALAPPDATA%\TrioBoard\models.
  • В портативном режиме файлы сохраняются локально в папке data рядом с программой.

2. Голосовой ввод (микрофон) и живой предпросмотр

  • По умолчанию используется локальный движок Whisper: звук с микрофона обрабатывается только на вашем компьютере и не передаётся в интернет.
  • Контекст окна и защита паролей: в Приватном режиме, а также при фокусе на полях паролей и менеджерах паролей, подсказки контекста активного окна автоматически отключаются.
  • Облачные режимы по вашему выбору: только если вы сами включили «Gemini (API)», «Авто: Gemini → Whisper» или «AI-обработка текста» и указали свой ключ API, аудио или распознанный текст отправляются напрямую в Google Gemini API.

3. Перевод текста и озвучка (TTS)

  • Локальное чтение (системные голоса Windows SAPI и опциональный внешний движок Piper CLI) и локальный перевод выполняются полностью на вашем компьютере.
  • При выборе онлайн-сервисов (Google Translate, MyMemory, Microsoft Edge Neural TTS, Google Cloud, Gemini или Grok) выбранный вами текст отправляется напрямую соответствующему провайдеру в момент нажатия кнопки или горячей клавиши.

4. История, Приватный режим и отчёты диагностики

  • История буфера хранится локально (по умолчанию до 50 последних записей).
  • При включении Приватного режима запись новых фраз в историю приостанавливается, а онлайн-озвучка отключается.
  • Технические журналы (app.log) хранятся только локально; при копировании отчёта поддержки API-ключи и токены автоматически маскируются.

5. Лицензирование и покупки

7-дневный пробный период и дневные счётчики бесплатного режима вычисляются локально на устройстве без регистрации аккаунта. Покупки TrioBoard Pro через Microsoft Store обрабатываются платформой Microsoft в соответствии с Политикой конфиденциальности Microsoft; активация промо-ключом TBPRO-... проверяется локально без обращения к внешним серверам.

6. Удаление данных и контакты

Вы можете в любой момент очистить историю в интерфейсе программы или удалить папку %LOCALAPPDATA%\TrioBoard. При удалении приложения через Windows Store локальные данные приложения удаляются средствами Windows.

1. Zero Telemetry & Local Storage

TrioBoard is built with a privacy-first architecture. The app does not collect hidden telemetry, keystroke analytics, usage tracking, or advertising identifiers, and never sells or sends your data to the developer.

  • When installed from Microsoft Store (MSIX) or a protected system folder, settings, snippets, dictionary, clipboard history, user-supplied API keys, and downloaded models are stored strictly locally inside %LOCALAPPDATA%\TrioBoard\data and %LOCALAPPDATA%\TrioBoard\models.
  • In portable mode, user data is stored locally in the data folder next to the application.

2. Microphone & Voice Dictation

  • Local Whisper by default: Microphone audio is processed offline on your PC and never leaves your device.
  • Password & privacy protection: Active-window context hints are automatically disabled in Privacy Mode and inside password fields or password managers.
  • Optional Cloud AI: Only if you explicitly select "Gemini (API)", "Auto: Gemini → Whisper", or enable AI text cleanup with your own API key will audio or dictated text be sent directly to Google Gemini API.

3. Translation & Text-to-Speech (TTS)

  • Local voices (Windows SAPI and optional external Piper CLI) and offline translation run entirely on your device.
  • If you choose an online engine (Google Translate, MyMemory, Microsoft Edge Neural TTS, Google Cloud, Gemini, or Grok), only the selected text is transmitted directly to that service upon your explicit request.

4. History, Privacy Mode & Diagnostic Logs

  • Clipboard history is saved locally (50 recent items by default).
  • Enabling Privacy Mode stops saving new history entries and blocks online TTS playback.
  • Technical logs (app.log) stay on your PC; using "Copy Support Report" automatically masks any API keys or bearer tokens.

5. Licensing & Store Purchases

The 7-day Pro Trial and daily free counters are tracked locally with no user account required. In-app upgrades to TrioBoard Pro are processed securely by Microsoft Store under Microsoft's Privacy Statement. Offline promo keys (TBPRO-...) are verified locally with zero network requests.

6. Data Removal & Contact

You can clear history inside TrioBoard anytime or delete %LOCALAPPDATA%\TrioBoard. Uninstalling the Microsoft Store package removes app-managed storage via Windows.

1. אפס טלמטריה ושמירה מקומית במכשיר

TrioBoard בנויה מתוך מחויבות מלאה לפרטיות. האפליקציה אינה אוספת סטטיסטיקות שימוש, אינה עוקבת אחר הקשות מקלדת ואינה שולחת מידע למפתחים או לגורמי פרסום.

  • בהתקנה דרך Microsoft Store (MSIX), ההגדרות, מילון המונחים, קיצורי הטקסט, היסטוריית הלוח, מפתחות ה-API שהזנת והמודלים שהורדת נשמרים מקומית בלבד בתיקייה: %LOCALAPPDATA%\TrioBoard.
  • במצב נייד (Portable), הנתונים נשמרים מקומית בתיקיית data לצד הקבצים.

2. שימוש במיקרופון והכתבה קולית

  • ברירת מחדל אופליין (Whisper): עיבוד הדיבור מתבצע מקומית על המחשב שלך בלבד ואינו נשלח לאינטרנט.
  • הגנת סיסמאות: במצב פרטיות ובחלונות של מנהלי סיסמאות, קריאת ההקשר של החלון הפעיל מושבתת אוטומטית.
  • מצבי ענן אופציונליים: רק אם בחרת בעצמך להשתמש ב-Gemini API או בעריכת AI והזנת מפתח אישי, האודיו או הטקסט נשלחים ישירות לשירות Google Gemini.

3. תרגום והקראת טקסט (TTS)

  • קולות המערכת של Windows, מנוע חיצוני אופציונלי Piper CLI ותרגום מקומי פועלים במלואם במחשב ללא חיבור רשת.
  • בבחירת מנועי רשת (Google Translate, MyMemory, Edge Neural TTS, Google Cloud, Gemini או Grok), רק הטקסט שביקשת לתרגם או להקריא נשלח ישירות לשירות הנבחר.

4. היסטוריה, מצב פרטיות ויומני מערכת

  • היסטוריית הלוח נשמרת מקומית בלבד. הפעלת מצב פרטיות עוצרת שמירה חדשה להיסטוריה וחוסמת הקראה מקוונת.
  • קובץ היומן (app.log) נשמר מקומית; בעת העתקת דוח תמיכה מפתחות API מוסתרים אוטומטית.

5. רישוי ורכישות

תקופת הניסיון ל-7 ימים ומונה השימוש היומי בחינם מנוהלים מקומית ללא הרשמה. רכישת TrioBoard Pro מתבצעת דרך Microsoft Store בהתאם למדיניות הפרטיות של Microsoft.
